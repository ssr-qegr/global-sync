🇨🇳 国内

我国修订《集成电路布图设计保护条例》，芯片设计知识产权保护继续加码

📰 新闻原文摘要

国务院公布修订后的《集成电路布图设计保护条例》，将于 2026 年 10 月 15 日起施行。新规明确布图设计登记申请必须以真实创作活动为基础，增加独创性声明要求；对明显不符合规定的申请可驳回，对已登记但不符合规定的可以撤销，同时在侵权赔偿上引入更强保护与惩罚性赔偿安排。

🗣️ 人话翻译

这不是单纯喊“支持芯片产业”，而是开始把芯片设计这类核心无形资产的确权、审查和维权规则补得更细、更硬，减少“蹭登记”“假原创”和低成本侵权。

💡 意义解读

对芯片设计公司、IP 授权公司和半导体创新团队来说，规则更清楚就意味着投入回报更可预期。它释放的信号是：产业升级不只靠投资和补贴，也要靠更强的制度保护把创新成果留住。

来源：国家知识产权局：就《集成电路布图设计保护条例》修订答记者问；Xinhua：China issues revised regulation on protection of IC layout-designs
🌍 国际

伊朗称与阿曼就霍尔木兹海峡谈判进入最后阶段

📰 新闻原文摘要

伊朗外长表示，伊朗与阿曼围绕霍尔木兹海峡相关安排的谈判已进入最后阶段。霍尔木兹海峡是全球能源运输的关键通道，该表态被市场视为中东局势中一个与油运和航运安全直接相关的重要进展。

🗣️ 人话翻译

意思就是，这条全球最敏感的“油气咽喉”可能离缓和更近了一步，但在真正敲定前，市场还不敢完全放下警惕。

💡 意义解读

只要霍尔木兹海峡风险没有彻底解除，油价、航运费率和全球通胀预期就都可能被地缘政治牵着走。谈判进入尾声本身是利好，但真正能让风险溢价下来的，是后续执行结果而不是口头表态。

🏦 国内财经

7 月 PMI 回落至 49.2%，高技术制造业仍保持扩张

📰 新闻原文摘要

国家统计局数据显示，7 月制造业 PMI 为 49.2%，非制造业商务活动指数为 49.0%，综合 PMI 产出指数为 49.3%，景气度较上月有所回落。不过，装备制造业和高技术制造业 PMI 分别为 51.4% 和 53.3%，仍处于扩张区间。

🗣️ 人话翻译

整体经济节奏确实比上个月慢了一点，淡季、天气和需求回落都在拖后腿，但“新质生产力”相关板块还没熄火，先进制造还在撑场面。

💡 意义解读

这组数据说明稳增长政策仍有继续发力的必要，但也提示市场别把“整体放缓”和“所有行业都差”画等号。接下来更可能出现的是总量温和、结构分化，政策和技术双加持的板块更容易跑出来。

来源：国家统计局：2026 年 7 月中国采购经理指数运行情况；国家统计局解读：高技术制造业持续扩张
🌍 国际财经

三位美联储反对票官员公开主张加息，全球资产重新定价压力升温

📰 新闻原文摘要

在美联储本周维持利率不变后，三位投下反对票的联储官员公开表示，若不尽快上调短端利率，通胀可能持续停留在 2% 目标上方；另有官员认为更紧的政策有较强理由，只是可以结合最新通胀数据再观察。

🗣️ 人话翻译

换句话说，联储内部并没有形成“放心不动”的共识，鹰派担心的是：现在不先轻轻踩刹车，后面可能就得更猛地踩。

💡 意义解读

对全球市场来说，这会直接抬高“高利率维持更久”的概率。只要这种预期重新升温，成长股估值、新兴市场资金流向和汇率波动都容易再次承压。

DeepSeek-V4-Flash 正式版 API 上线公测，国产 Agent 模型能力继续前推

📰 新闻原文摘要

DeepSeek 在 7 月 31 日更新日志中宣布，DeepSeek-V4-Flash 正式版 API 已上线公测，调用方式保持不变；官方同时强调，该版本原生支持 Responses API 格式，并针对 Codex 做了适配，重点强化了 Agent 能力。

🗣️ 人话翻译

这说明国内大模型厂商不再只卷聊天体验，而是在加速冲向“能不能真正接入开发工作流、能不能把 Agent 跑起来”这条更实用的赛道。

💡 意义解读

当模型开始原生适配开发者工具链，竞争焦点就会从“谁更会回答问题”转到“谁更容易接进业务系统”。这对开发平台、企业内工具和自动化工作流都是利好，也意味着国产模型生态进入更重交付的阶段。

来源：DeepSeek API 文档：更新日志
🌐 国际技术

OpenAI 下调 GPT-5.6 Luna 与 Terra 价格，企业级大模型进入更激烈性价比战

📰 新闻原文摘要

OpenAI 宣布自 7 月 30 日起调整 GPT-5.6 系列两款模型 API 价格：Terra 输入/输出价格调整为每百万 token 2 美元和 12 美元，Luna 调整为 0.20 美元和 1.20 美元。官方强调这是继续推进能力与效率双提升的一部分。

🗣️ 人话翻译

意思很明确：头部模型厂商现在不仅要比谁更强，还要比谁更便宜、谁更适合大规模商用，价格战已经从边缘选手打到了第一梯队。

💡 意义解读

一旦大模型 API 价格继续下探，企业试水 AI 的门槛会更低，应用层落地速度会更快，同时也会倒逼整个行业在成本控制、模型路由和商业模式上全面升级。
