AI 编程代理 / 自动化

OpenHands Agent Canvas：把“代码代理”变成可控、可切换、可自动化的工程工作台

OpenHands Agent Canvas 是一个自托管（self-hosted）的开发者控制中心：你可以在同一个界面里运行 OpenHands、Claude Code、Codex、Gemini 等 ACP 兼容的 coding agent，并把它们接到本地、Docker、远端 VM 或云端后端上，实现“同一套工作流，多个后端随时切换”。

技术亮点包括：支持多种 Agent Backend（本地/容器/虚机/企业基础设施）并在 UI 中快速切换；可以编排自动化任务（例如定时生成报告、把 GitHub Issue 自动拆解成任务等）；同时支持“自带模型”或接入第三方 agent，适配不同成本/速度/效果诉求。

适用场景：把它当成团队的“AI 工程队”控制台——长驻在一台服务器上持续运行；处理重复性的工程事务（Issue triage、报告、代码 review 辅助、依赖/文档维护）；或者作为个人开发的 agent 实验平台，快速验证不同 agent/模型/工具链组合的效果。

自托管 LLM 平台 / RAG

Open WebUI：离线可跑的“自建 ChatGPT”，支持 Ollama + OpenAI-Compatible API + RAG

Open WebUI 是一个可扩展、功能丰富、对用户友好的自托管 AI 平台，设计目标之一就是可以在本地/内网环境里“完全离线”运行；它既能连本地的 Ollama，也能对接任何 OpenAI-compatible API（例如 vLLM、OpenRouter 等），并内置面向 RAG 的能力，适合做团队共享的 AI 入口。

技术亮点包括：多模型/多提供方自由组合；细粒度的 RBAC 与用户组；插件体系（Filters/Actions/Pipes/Tools/Skills）用于扩展能力与接入外部服务（含 MCP/OpenAPI 工具服务器）；本地知识库 + 向量检索的 RAG；以及团队协作能力（频道/笔记/持久化记忆等），更接近“可运营的 AI 内部门户”。

适用场景：快速搭建一个“公司/团队的 AI 工作台”，统一接入本地模型与云模型；用 RAG 把内部文档/规范/代码知识库接进去，做检索式问答；给非研发同学提供可控的 AI 界面与权限；或者在个人机器上配合 Ollama 做本地隐私友好的 AI 助手。
