1. agentgateway/agentgateway

面向 AI Agents、MCP 和 A2A 的统一代理与控制平面

TOP 1
🛡️ Governance🔌 MCP Gateway🤝 A2A Gateway🧠 LLM Gateway📈 Observability☁️ Kubernetes

项目详细介绍：Agentgateway 是一个围绕 AI 原生协议构建的开源代理层，目标不是只做一个“转发器”，而是把 LLM 调用、MCP 工具调用、A2A 协作、推理流量路由、安全策略和可观测性统一收拢到一个控制平面里。它既能面向 OpenAI 兼容的模型调用场景，也能面向工具接入和 Agent 间通信场景，更适合真正准备把 Agent 能力落到团队和企业环境里的工程师关注。

技术亮点

  • 三层网关合一：项目同时提供 LLM Gateway、MCP Gateway 和 A2A Gateway，不用为不同协议各自再搭一套基础设施。
  • 统一策略治理：官方 README 明确包含 JWT、API Key、OAuth、RBAC、限流、TLS 与 OpenTelemetry，说明它关注的是生产环境真正会碰到的权限与审计问题。
  • 推理路由能力：支持把自建 GPU 推理集群纳入统一调度，结合队列深度、缓存命中、LoRA 等信息决定路由，更接近平台级基础设施。
  • OpenAPI 与多传输适配：MCP 侧不仅支持 stdio / HTTP / SSE / Streamable HTTP，还支持 OpenAPI 集成，利于把存量接口逐步接入 Agent 工具链。
  • 运维可见性较强：官网把 traces、logs、policy decisions、audit logs 都放在核心卖点里，适合有平台治理诉求的团队。

使用场景

  • 企业级 Agent 平台：内部已经有多个模型、多个 MCP Server、多个 Agent 服务时，可以用它做统一接入层。
  • 安全敏感的工具调用：当你希望每次工具调用都带身份、权限、审计和追踪，而不是“谁都能调”时，这类网关就很关键。
  • 多模型路由与成本控制：想在不同任务之间切换不同模型或自建推理后端时，统一网关比散落在业务里更好维护。
  • Kubernetes 上的 Agent Infra：如果你的落地场景本来就在 K8s 上，Agentgateway 的控制面和文档体系更容易接进现有平台。

为什么今天推荐它

  • 现在大家都在做 Agent，但很多团队缺的不是单个 Demo，而是“怎么安全接进生产环境”的工程答案。
  • Agentgateway 给出的不是 prompt 技巧，而是平台化治理思路，这对技术成长更有长期价值。
  • 如果你未来想做内部 AI 平台、智能研发中台、工具网关或模型网关，这个项目很值得持续跟进。

2. oraios/serena

给 AI 编码助手补上 IDE 级语义检索、编辑与重构能力

TOP 2
🧩 Semantic Retrieval🛠️ Symbol-level Editing🔗 MCP🧠 LSP💻 JetBrains📚 40+ Languages

项目详细介绍：Serena 是一个面向 AI Coding 场景的 MCP 工具包，核心价值在于让模型不再只靠全文搜索和行号替换去“盲改代码”，而是像开发者在 IDE 里一样，以符号、引用关系和结构化语义为中心进行检索、编辑、重构和调试。它既能通过 LSP 提供开源路线，也支持结合 JetBrains 插件使用，更像是“AI 助手的 IDE 能力层”。

技术亮点

  • 符号级代码操作：官方 README 明确支持 semantic retrieval、symbolic editing、refactoring，不再只是粗暴的 search & replace。
  • MCP 友好接入：可以作为 MCP Server 接到 Claude Code、Codex、Gemini CLI、Claude Desktop、Cursor 等现代客户端里。
  • 多语言覆盖广：默认基于语言服务器后端，官方文档列出支持超过 40 种编程语言，适合多语言仓库与大型项目。
  • 编辑更稳：像 rename、replace symbol body、insert before/after symbol 这类操作，本质上比文本级替换更可靠，也更省 token。
  • 可扩展工作流：除了检索和编辑，它还带有 memory system 与多层配置能力，适合长生命周期的 agent workflow。

使用场景

  • 大仓库 AI 编码：当模型总是读太多、改太散时，Serena 能帮助它更快定位真正相关的符号与依赖关系。
  • 跨文件重构：重命名、移动、引用查找、依赖跳转等任务，特别适合用符号级工具替代文本硬改。
  • 多语言项目维护：一个仓库同时有 Go、TypeScript、Python 等语言时，语言服务器路线会比手工拼工具更统一。
  • 增强现有 AI 客户端：如果你已经在用 Claude Code、Codex 或 Cursor，这个项目很适合作为“外挂式能力补强”。

为什么今天推荐它

  • AI Coding 进入实战阶段后，真正拉开体验差距的往往不是模型本身，而是上下文获取和代码操作是不是足够语义化。
  • Serena 把 IDE 里本来就成熟的能力通过 MCP 暴露给 AI 助手，这个方向非常务实，也非常适合工程团队落地。
  • 如果你平时就在大仓、老仓或多语言仓库里写代码，这类工具的价值会比“再换一个模型”更直接。
